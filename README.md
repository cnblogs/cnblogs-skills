# Agent 的经验，不该只留在聊天框里：cnblogs-publish 上线

> 本仓库是博客园官方 Agent Skills 集合，当前包含 `cnblogs-publish`，后续 skill 会继续放在 `skills/` 下。

我们每天都在和 AI Agent 协作。

让它读代码、查资料、排故障、理思路。过程中总会冒出一些好问题，也会踩过一些坑，最后形成一套亲测有效的解法。

可对话一关，这些经验就散了。

散落在会话记录里，散落在临时笔记里，散落在“下次一定整理”的待办里。

现在，博客园正式推出 **cnblogs-publish** skill。

它要做的事很简单：**让 Agent 把刚刚发生的协作，整理成一篇博文，然后一键发布到博客园。**

## 一句话，让 Agent 自己发博客

启用 skill 后，你只需要对 Agent 说：

> 把我们刚才排查问题的过程，总结成一篇博文，发布到博客园。

Agent 会整理标题、正文、标签和分类，调用 cnblogs-publish 完成发布。你负责提出好问题，它负责把答案留下来。

## 默认私有：先安心存下来

发布默认是**非公开**的，仅自己可见。

私有博文不会被公开搜索和推荐，也不会进入审核流程。它更像一个安全的个人知识库：

- 还没想清楚的草稿，先存；
- 只对自己有用的排查记录，先存；
- 涉及内部信息、暂时不能分享的经验，先存。

不用担心“发出去就被看到”。私有博文不会进入审核，也不需要等待审核——只有公开发布时才需要审核。

另外，凭据只保存在操作系统的安全凭据库里，不会出现在聊天记录、命令参数或日志中。你的账号，还是你的账号。

## 想分享时，再说一句“公开发布”

当一篇内容打磨得差不多了，你可以对 Agent 说：

> 这篇可以公开，发布吧。

公开发布后，文章才会对外可见。

需要说明的是：**公开发布要经过博客园审核团队的审核**，通过后才会公开传播。这是为了挡住不和谐内容，符合内容安全要求，也是对读者的负责。

审核期间，首页和公开页面暂时看不到文章，不代表发布失败。稍等一会儿，让内容飞一会儿。

如果这篇格外满意，还可以让 Agent 选择**发布到首页**，让更多读者看到你的杰作。好内容值得被看见，首页推荐同样需要经过审核。

## 不止发布，还能“读”和“管”

cnblogs-publish 不只是一个发布按钮。

你还可以让 Agent：

- **查询自己的博文**：“翻出我以前写过的性能优化文章，结合它回答我。”
- **直接阅读旧文**：把过去沉淀的经验，变成这次对话的上下文。
- **更新文章**：补充新发现，修正旧结论。
- **删除文章**：清理过时内容，保持知识库干净。
- **上传图片、设置分类和标签**：让文章更完整、更好找。

写得越多，Agent 越懂你的经验。下一次遇到相似问题，它不只是从零推理，还能接着你过去的思考继续往前走。

## 默认透明：内容来源标注

默认情况下，发布时会在正文顶部加一条来源声明，提醒读者内容由 AI 生成或经 AI 辅助完成。

如果你不需要，也可以让 Agent 关闭。

保留它，是对读者的尊重；关闭它，由你决定。

## 三步开始

1. 在 Agent 中启用 cnblogs-publish skill；
2. 对 Agent 说：“把这次讨论总结成一篇博文，发布到博客园”——默认私有；
3. 想分享时，再说一句：“公开发布”或“发布到首页”。

从今天起，别让好问题只停留在聊天框里。

让 Agent 帮你写下来，存进博客园，也留给未来的自己。

## 把这个地址交给 Agent

```text
https://github.com/cnblogs/cnblogs-skills/tree/main/skills/cnblogs-publish
```

对 Agent 说：

> 从这个地址安装 cnblogs-publish skill，然后帮我把这篇文章发布到博客园。

Agent 会自行下载、安装并学习使用方法。默认发布为私有。
